# Backups

Dated copies of the notebook, exactly as **Export** wrote them — one file is
the whole thing: schedule, reminders, expenses, splits, wishlist, saved
phrases, labels, settings, and every attachment inlined as a data URL.

Nothing here is built or served. Pages publishes `dist/` only, so these files
live in the repo and never appear on the site.

## Restoring one

Open the app, and in the backup bar choose **Import**, then pick the file.
Import *adds to* the notebook rather than replacing it. To start clean
instead, use **Replace** and confirm.

## Adding one

Press **Export**, then drop the downloaded file in here under its own date.
Keep the name the app gave it — `scheduleplan-YYYY-MM-DD.json`.
